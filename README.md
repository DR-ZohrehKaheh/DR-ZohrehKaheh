## Latest project

### [AI Delivery Risk Intelligence](https://github.com/DR-ZohrehKaheh/ai-delivery-risk-intelligence)

A Python research prototype for e-commerce delivery-risk ranking and interactive decision support, developed by Zohreh Kaheh. It combines **XGBoost, scikit-learn and Streamlit** with temporal validation, probability-calibration diagnostics and bootstrap intervals for performance metrics.

The project includes single-order and batch risk scoring, a dashboard preview, research notebooks, automated tests and documented historical evaluation results. It is a research demonstration; operational deployment has not been validated.

## How to explore this portfolio

Each README explains the purpose, required inputs, execution steps and limitations. In the three collaborative projects, `ATTRIBUTION.md` records contributions and disclosed AI assistance, and `VERIFICATION.md` describes the tested workflow and environment. AI Delivery Risk Intelligence documents its methods, historical results and limitations in its README and notebooks, with dataset-independent tests in GitHub Actions.

For citation, use the project’s `CITATION.cff` or `CITATION.bib`, which identify the authors and archived version. The DOI links above refer to fixed snapshots; later GitHub documentation may differ. Technical questions and documentation corrections can be raised through the relevant repository’s Issues page.

**Reuse status:** No repository-wide software reuse licence has been granted. For the three collaborative projects, student contributions have publication-only permission; each repository’s `LICENSE_STATUS.md` explains the status. AI Delivery Risk Intelligence records its source-code permissions in [`RIGHTS.md`](https://github.com/DR-ZohrehKaheh/ai-delivery-risk-intelligence/blob/main/RIGHTS.md). Citation does not grant reuse permission.

The repositories contain code and technical documentation; raw research datasets and trained model binaries are excluded. AI Delivery Risk Intelligence also includes aggregate historical evaluation summaries. Verification is limited to the scope documented in each repository; operational deployment has not been validated.
