## How to explore this portfolio

Each README explains the purpose, required inputs, execution steps and limitations. `ATTRIBUTION.md` records contributions and disclosed AI assistance; `VERIFICATION.md` describes the tested workflow and environment. Dependencies and file checksums accompany the code.

For citation, use the project’s `CITATION.cff` or `CITATION.bib`, which credit both contributors and identify the archived version. The DOI links above refer to fixed snapshots; later GitHub documentation may differ. Technical questions and documentation corrections can be raised through the relevant repository’s Issues page.

**Reuse status:** These are public research repositories with publication-only permission for student contributions. No repository-wide reuse licence has been granted. Each project’s `LICENSE_STATUS.md` explains the status; citation does not grant reuse permission.

These repositories contain code and technical documentation. Manuscripts, research datasets, stored research results and trained models are excluded. Execution verification applies to the documented workflow and environment; operational deployment has not been validated.
